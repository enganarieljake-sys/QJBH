# Queen Jackie Boarding House Recovery Report

Recovery date: 2026-10-11 (Asia/Manila)

## Outcome

The Vercel account and team ownership were verified through the official Vercel CLI browser login. Deployment `dpl_Dbjt9f1B86osSTTZkhWTFmuobG61` is accessible, belongs to project `queenjackie-bh`, and reported `READY`.

Vercel's documented deployment-file APIs returned 285 source files. All 285 were downloaded successfully, with no download errors. The `src/` API namespace was mapped to this project's root; filenames and hierarchy below that namespace were preserved.

The API tree also contained an `out/api/index` entry of type `lambda`. It is a deployment runtime artifact rather than an original source file and was not exposed as a downloadable file by the source-file endpoint. Its authentic source entry point, `api/index.php`, was recovered.

Detailed API evidence and the per-file manifest are retained locally under `_recovery/` and excluded from Git.

## Not recovered from Vercel

The recovered `.vercelignore` proves that these paths were intentionally excluded from the deployment source upload and therefore could not be recovered through the deployment file API:

- `.env` and other environment files except `.env.example`
- `vendor/`
- `node_modules/`
- `public/build/`, `public/hot`, and `public/storage`
- runtime contents under `storage/`
- `tests/`

No production secrets were retrieved. No production database was present in the deployment source. The uploaded `database/database.sqlite` was an empty zero-byte file. Restoring production data would require a separately authorized database backup or provider export.
